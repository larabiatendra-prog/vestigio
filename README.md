# Vestigio

**El conocimiento que permanece.**

Vestigio es una biblioteca técnica y práctica completamente offline para Windows. Vive en una carpeta portable que arranca desde un USB sin instalación ni permisos de administrador, conserva documentos originales (PDF, EPUB, HTML, Markdown, TXT, ZIM), los hace buscables sin IA y añade capas de aprendizaje, aplicación práctica y modo emergencia. Está pensada para seguir siendo útil aunque no haya Internet, y para escenarios de degradación en los que el conocimiento práctico importa más que nunca.

Es un producto personal, de un solo usuario, del ecosistema NODO.

## Qué contiene este repositorio

Código, herramientas, esquemas, documentación, metadata publicable y fixtures pequeños. **No contiene el corpus** (los documentos de la biblioteca), ni datos personales, ni claves de firma: tests de guardia en `tests/guard/` lo verifican en cada ejecución de CI.
